# 调研结论

每份调研单对应一个文件：`B-XX-<slug>.md`。文件名与单子编号一致，便于互查。

## 模板

```markdown
# B-XX 关于……

- 调研人：
- 完成日期：
- 对应单子：`briefs/B-XX-*.md`
- 状态：完成 / 部分完成 / 受阻

## 1. 结论（≤5 行）

## 2. 证据

| 编号 | 类型 | 内容 | 来源/链接 | 日期 |
|---|---|---|---|---|

## 3. 对设计的影响

- 字段/数据模型：
- 指标/算法：
- 界面/交互：
- 文档/答辩：

## 4. 分歧与未解决

## 5. 下一步建议
```

## 规则

- 结论先行；不要按调研过程写流水账。
- 访谈对象用 `P01`、`O01` 编号，不写真名。
- 引用外部资料必须带链接与访问日期；预印本要标注。
- 与单子里的验收标准逐条对照，不达标就写"未达标 + 原因"。
- 结论被后续推翻时，不删原文，在文件顶部加"已被 B-XX 取代"。
