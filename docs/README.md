## 写作约定

- 结论先行；能表格就不写长段落。
- 数字必须注明来源或标注"目标值/估计值"。
- 不确定的地方写清楚"假设"与"复核条件"，不要用模糊语气掩盖。
- 文档间引用用相对路径 + 锚点。
