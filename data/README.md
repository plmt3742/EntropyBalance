# data

按**可提交性**分三层。这条边界是硬性的：进错目录就是把别人的聊天记录推到公开仓库。

| 目录 | 内容 | 是否入库 |
|---|---|---|
| `raw/` | 原始记录、导出文件、数据库、映射表 | **永不入库**（`.gitignore`） |
| `samples/` | 脱敏后的演示样例，能直接给评委看 | 入库 |
| `golden/` | 脱敏标注集与评测口径 | 入库 |

## 脱敏检查（提交前逐项过）

- [ ] 无真实姓名、昵称、手机号、微信号、邮箱
- [ ] 无组织名、项目代号、可反查的专有名词
- [ ] 无地址、金额、合同条款等敏感业务信息
- [ ] 人名替换为稳定代号（如 `P01`），且不同文件间一致
- [ ] 时间只保留到日，必要时整体平移
- [ ] 已确认原始映射表不在同一目录

## 禁止

- 用"改一两个字"代替脱敏。
- 把 `raw/` 的文件复制到 `samples/` 后忘记检查。
- 把含真实数据的截图放进文档或演示视频。
