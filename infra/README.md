# infra

构建与部署。

## 目标形态

- 多阶段构建：Node 构建前端 → Python 运行时。
- 单进程单端口：FastAPI 同时提供 `/api` 与前端静态文件。
- SQLite 文件与演示快照随镜像/挂载提供，启动即可用。
- 回放模式不触网。

## 目录

| 路径 | 内容 |
|---|---|
| `docker/` | Dockerfile、compose、启动脚本 |

具体文件在骨架阶段创建。部署细节与降级路径见 `docs/20-architecture/system-overview.md`。

## 规则

- 镜像不包含 `data/raw/`、`.env`、真实姓名映射表。
- 默认不暴露公网端口；需要公网演示时单独加口令与脱敏数据。
- 启动失败要打印可读原因（缺模型密钥 / 缺快照 / 端口占用），不能只有堆栈。
